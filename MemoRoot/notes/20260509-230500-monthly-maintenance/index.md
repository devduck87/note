# 月次メンテナンスルーティーン

毎月 1 日に確認する、PC・データ・健康まわりの定期チェック項目。
本ノートではチェックを付けず、本日プランから daily ノートへ展開された側でチェックする。 ^monthly-routine

## PC・開発環境

- [ ] OS / ドライバの更新を確認
- [ ] バックアップが正常に取れているか確認
- [ ] 不要になった venv / node_modules を整理
- [ ] ディスク使用量を確認 (Cドライブ残量)

## データ・アカウント

- [ ] パスワード管理ツールの監査ログを確認
- [ ] クラウドストレージの容量を確認
- [ ] 月次の家計を集計

## 健康・生活

- [ ] 体重を記録
- [ ] 飲み忘れた薬がないか確認
- [ ] 防災備蓄の賞味期限を 1 つだけ確認
