# Excel検索ツールの使い方 2026-05-07

> テンプレート: [[Excel検索ツールの使い方]]

実施担当: 自分
対象: 田中さんへの操作レクチャー (オンラインミーティング)

## 起動手順

1. [x] デスクトップの **ExcelSearch.exe** をダブルクリック
2. [x] 初回のみ、検索対象フォルダを設定する
   - メニュー > 設定 > 検索対象フォルダ追加
3. [x] **インデックス再構築** ボタンを押す（数分かかる場合あり）

## 検索のコツ

- [x] AND 検索: スペース区切りで複数キーワード
- [x] フレーズ検索: ダブルクォートで囲む `"締切日"`
- [x] シート名で絞り込み: `sheet:見積` のように prefix を付ける

## 注意事項

- [ ] パスワード保護された Excel は読み込めない
- [x] マクロ付き (`.xlsm`) は本文のみ抽出（マクロは無視）
