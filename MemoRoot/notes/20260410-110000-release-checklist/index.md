# リリース手順チェックリスト


リリース時にこのチェックリストを「使う」操作でインスタンス（type=log）を生成し、
インスタンス側で進捗を埋めていく。
元テンプレートはチェックを付けないこと。


## 事前準備

- [ ] リリース対象のコミットを確定する
- [ ] CHANGELOG を更新する
- [ ] バージョン番号をタグ付けする
- [ ] 関係者にリリース通知メールを送る

## ビルド・配布

- [ ] Release ビルドを作成する
- [ ] バイナリを共有フォルダへ配置する
- [ ] 配布パスを通知メールに追記する

## 動作確認

- [ ] 自分の PC で起動確認
- [ ] サンプルデータで主要機能を動かす
- [ ] 既知の不具合一覧を確認
