# LVGL バッファ設定メモ

## ダブルバッファ vs シングルバッファ

LVGL の描画バッファはサイズと数で性能が大きく変わる。

- **シングルバッファ**: メモリは少ないが、描画中にちらつきが出る
- **ダブルバッファ**: 倍のメモリが必要だが滑らか
- **フルダブルバッファ**: フレームバッファ全体 × 2。最も滑らか、最もメモリ食う

## 推奨サイズ

画面解像度の **1/10** が初期値の目安。

```c
static lv_color_t buf1[DISP_HOR_RES * DISP_VER_RES / 10];
static lv_color_t buf2[DISP_HOR_RES * DISP_VER_RES / 10];
```

## 注意点

- DMA 使うなら align アクセス可能領域に置く
- SRAM の連続領域を確保できるか要確認
- 内蔵 RAM が足りなければ外部 PSRAM を検討
